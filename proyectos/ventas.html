Dashboard de ventas comerciales

La gerencia comercial armaba el reporte de ventas a mano en Excel cada mes. Construí un dashboard en Power BI que se actualiza solo y muestra ventas, margen y clientes por región.

  • Power BI
  • DAX
  • Power Query
  • SQL Server
6 h → 15 mintiempo del reporte mensual
40+usuarios en el área comercial
5fuentes de datos integradas

Vista general. Datos ficticios con la misma estructura que el original.

El problema

Describe en 2 o 3 frases la situación antes del dashboard: quién lo necesitaba, qué dolía y qué decisión no se podía tomar bien.

Datos y proceso

  • Fuentes: ERP en SQL Server, metas en Excel, maestro de clientes en SharePoint.
  • Transformación: limpieza y unión en Power Query; actualización programada diaria.
  • Modelo: esquema estrella con una tabla de hechos de ventas y dimensiones de fecha, cliente, producto y región.
  • Diseño: una página ejecutiva y páginas de detalle con obtención de detalles (drill-through) por cliente.

Una medida DAX destacada

Ventas YoY % =
VAR Actual = [Ventas]
VAR Anterior = CALCULATE ( [Ventas], SAMEPERIODLASTYEAR ( 'Fecha'[Fecha] ) )
RETURN DIVIDE ( Actual - Anterior, Anterior )

Resultado

Qué cambió después: tiempo ahorrado, decisiones que se tomaron, quién lo usa hoy.

Por confidencialidad, los nombres, montos y regiones de este caso fueron reemplazados por datos ficticios.
