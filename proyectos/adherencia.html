Calidad de planificación de rutas

Un software de ruteo propone las rutas de reparto y los planificadores de cada cliente las ajustan antes de aprobarlas. Este dashboard mide cuánto se respetó el plan optimizado y avisa cuando la calidad de planificación viene cayendo, para que el equipo actúe antes de que el cliente lo note.

Problema

Cuando los planificadores cambian muchas rutas a mano, se pierde el ahorro que calculó el optimizador. No había una forma simple de ver quién se alejaba del plan ni si la situación mejoraba o empeoraba.

Solución

Indicadores ponderados de adherencia, salud y factibilidad del plan, analizables por cliente, organización, depot o planificador, con alertas automáticas cuando la calidad cae varias semanas seguidas.

Decisiones que permite

  • Detectar qué clientes, depots o planificadores se alejan del plan optimizado.
  • Anticipar caídas de calidad antes de que el cliente las note.
  • Priorizar dónde capacitar o conversar primero.
  • Relacionar la calidad del plan con distancia, ocupación y tamaño de entrega.

Resultado

El equipo lo revisaba todos los días para ver qué clientes, depots o planificadores se alejaban del plan, con alertas automáticas que indican dónde conversar primero.

Stack

Power BI · DAX · SQL (PostgreSQL) · Power Query · Parámetros de campo (Field Parameters)

Cómo se construyó

  • Fuente: consulta SQL sobre PostgreSQL que agrega los itinerarios aprobados de los últimos 14 meses y calcula ponderadores por demanda en la base de datos, para que el modelo cargue solo lo necesario.
  • Indicadores ponderados: adherencia de orden y de pertenencia de cada parada, ponderadas por la cantidad de demandas editadas, en vez de un promedio simple que favorecería a las rutas chicas.
  • Parámetros de campo: el usuario elige el indicador, la granularidad de fecha y la dimensión de análisis, y la matriz y el título cambian solos.
  • Segunda vista de desempeño: distancia promedio ponderada (WAD), ocupación por carga y por tiempo, tamaño de entrega y porcentaje de rutas manuales, con ejes X e Y seleccionables para comparar indicadores entre sí.

DAX destacado

Alerta que se enciende cuando un indicador cae varias semanas seguidas. Compara cada semana con la anterior y cuenta la racha actual de bajas.

Ver medida DAX → 
AvisoAdherencia =
VAR UltimaSemana = MAXX ( ALL ( Adherencia ), MAX ( Calendario[Semana] ) )
VAR PorSemana =
    ADDCOLUMNS (
        SUMMARIZE ( Adherencia, Calendario[Semana] ),
        "Valor", DIVIDE ( SUM ( Adherencia[ponderador_adherencia] ),
                          SUM ( Adherencia[edited_demands_divisor] ) )
    )
VAR ConTendencia =
    ADDCOLUMNS ( PorSemana, "Baja",
        VAR S = [Semana]
        VAR Ant = MAXX ( FILTER ( PorSemana, [Semana] < S ), [Semana] )
        VAR ValorAnt = MAXX ( FILTER ( PorSemana, [Semana] = Ant ), [Valor] )
        RETURN IF ( NOT ISBLANK ( ValorAnt ) && [Valor] < ValorAnt, 1, 0 ) )
VAR UltimaSinBaja = MAXX ( FILTER ( ConTendencia, [Semana] <= UltimaSemana && [Baja] = 0 ), [Semana] )
VAR Racha = COUNTROWS ( FILTER ( ConTendencia, [Semana] > UltimaSinBaja && [Semana] <= UltimaSemana ) )
RETURN IF ( Racha >= 2, "⚠️ 3 semanas bajando", "OK" )

Por confidencialidad, los clientes, depots, planificadores y cifras de este caso son ficticios.
