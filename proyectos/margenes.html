Problema

La información de rentabilidad, costos y presupuesto estaba distribuida en distintas planillas por área. Consolidarla tomaba días cada mes y no había una vista única para saber qué clientes dejaban margen ni cómo iba a cerrar el año.

Solución

Modelo integrado de rentabilidad, costos, presupuesto y forecast, con margen total y marginal por cliente y contrato, y comparación contra el mes anterior o el mismo mes del año pasado.

Decisiones que permite

  • Detectar clientes con deterioro de margen.
  • Identificar los drivers de costos.
  • Comparar la ejecución contra el presupuesto.
  • Proyectar el cierre anual.
  • Detectar desviaciones de forma anticipada.

Resultado

Gerencia y finanzas pasaron a revisar la rentabilidad por cliente y el avance del presupuesto en un solo lugar, en vez de consolidar planillas cada mes.

Stack

Power BI · DAX · Power Query · Excel

Cómo se construyó

  • Fuentes: planillas de rentabilidad mensual por contrato, dedicación de horas del equipo, gastos y presupuesto, unificadas en Power Query y llevadas a formato largo para analizar cualquier atributo con las mismas medidas.
  • Margen total y marginal: el margen marginal descuenta solo el costo que cambia con cada cliente, para separar los contratos que cubren su costo directo de los que además aportan a la estructura.
  • Comparación elegible: el usuario elige comparar el último mes contra el mes anterior o contra el mismo mes del año pasado, y cada tarjeta muestra la variación con su flecha.
  • Presupuesto con forecast: se combinan presupuesto, ejecución real y forecast para proyectar el cierre del año y medir el cumplimiento comercial.

DAX destacado

Proyección del año que usa lo ejecutado en los meses cerrados y el forecast en los meses que faltan, sin duplicar ni dejar huecos.

Ver medida DAX → 
Control + Forecast =
VAR MaxFechaControl =
    CALCULATE (
        MAX ( 'Presupuesto Compilado'[Date] ),
        'Presupuesto Compilado'[Budget Type] = "Control"
    )
RETURN
    SUMX (
        VALUES ( 'Presupuesto Compilado'[Date] ),
        VAR FechaActual = 'Presupuesto Compilado'[Date]
        VAR ControlMes =
            CALCULATE ( SUM ( 'Presupuesto Compilado'[Value] ),
                        'Presupuesto Compilado'[Budget Type] = "Control" )
        VAR ForecastMes =
            CALCULATE ( SUM ( 'Presupuesto Compilado'[Value] ),
                        'Presupuesto Compilado'[Budget Type] = "Forecast" )
        RETURN IF ( FechaActual <= MaxFechaControl, ControlMes, ForecastMes )
    )

Por confidencialidad, los clientes, contratos, personas y cifras de este caso son ficticios.
